# c-lexer

《编译技术》实验一：给 C 语言的一个子集写了个词法分析器。

它做的事很直接。读入一个 `.c` 文件，一行一行回显源程序，在每行下面列出这一行的记号，注释和空行顺手清掉；遇到写错的地方，指出第几行第几列。记号的输出按课程要求的二元式来。

## 目录里有什么

| 位置 | 内容 |
| --- | --- |
| `code\inc`、`code\src` | 源代码，四个模块加一个主程序 |
| `code\bin` | 编好的程序 `lexer-windows-x86_64.exe` |
| `code\examples` | 两个能直接跑的示例 |
| `code\tests` | 七组用例、期望输出和比对脚本 |
| `docs` | 使用说明、测试结果、开发与构建说明 |
| `《编译技术》实验一报告-词法分析器.pdf` | 实验报告 |

## 怎么用

最省事的是走 `run.bat`：

```bat
code\run.bat 你的代码.c
```

它干的事很朴素：先看 `code\bin` 里有没有现成的 exe，有就直接跑，没有再调用 CMake 编一份，编完接着跑。第一次用可能要多等十几秒，之后就是秒开。

想省掉这层包装，直接敲 exe 也一样：

```bat
code\bin\lexer-windows-x86_64.exe 你的代码.c
```

两条命令等价，路径里有中文、有空格都不影响。

不急着写自己的代码，可以先拿自带的例子试一下：

```bat
code\run.bat code\examples\simple.c
```

命令行只有一个参数 `-h`，打印用法。

## 跑出来长什么样

```
=== code\examples\simple.c ===
  1 | // 最小示例：整数与浮点各声明一次
  2 | int main()
    | (6,"int") (6,"main") (7,"(") (7,")")
  3 | {
    | (7,"{")
  4 |     int a = 3;
    | (6,"int") (1,"a") (7,"=") (2,"3") (7,";")
```

上面一行是源程序，前面带行号；下面缩进的那行是本行识别出的记号，括号里第一个数字是类别，第二个是它本身。行号右对齐，宽度跟着总行数走，三列起步，文件超过一千行也不会串位。空行和整行注释只有源程序那一行，下面不再出记号。

种别码的含义：

| 种别码 | 类别 |
| --- | --- |
| 1 | 标识符 |
| 2 | 整型常量 |
| 3 | 浮点常量 |
| 4 | 字符常量 |
| 5 | 字符串常量 |
| 6 | 保留字 |
| 7 | 运算符与界符 |
| 8 | 文件结束（不输出） |
| 9 | 词法错误 |

字符常量的属性值不带外层引号，`'x'` 是 `(4,"x")`，`'"'` 是 `(4,"\"")`。

末尾还有一段统计，给出行数、记号总数、错误数，以及按类别、按整型进制的计数。

## 写错的时候

程序不会中途罢工，会把错误一处一处列出来：

```
tests\cases\t05_error.c:2:10: E102 字符常量未闭合
  2 | char b = 'x;
    |          ^
```

前面是「文件:行:列: 编码 说明」，后面回显那一行，用 `^` 指着出问题的字符。

| 编码 | 含义 |
| --- | --- |
| E101 | 非法字符 |
| E102 | 字符常量未闭合 |
| E103 | 字符常量内容为空或超过一个字符 |
| E104 | 非法转义序列 |
| E105 | 字符串常量未闭合 |
| E201 | 十六进制常量缺少数字 |
| E202 | 八进制常量中出现 8 或 9 |
| E203 | 浮点常量缺少指数部分 |
| E204 | 非法的数值后缀 |
| E301 | 块注释未闭合 |
| E401 | 标识符长度超过 63 |

## 认哪些写法

保留字 21 个，直接从指导书的表格里抄的。表里 `unsigned` 出现了两遍，去重后就是 21 个：

```
auto  break  case  char  const  continue  do  double  else  enum
float if     int   long  main   return    static switch unsigned void while
```

运算符与界符：单字符 `+ - * / = < > ; ( ) { }`，双字符 `== != <= >= && ||`。

注释就两种，`//` 到行尾、`/* */` 可跨行，块注释不嵌套。花括号是普通的界符，和 C 里一个意思，函数体、`if`、`while` 的块都照常出记号，不会被当成注释吃掉。

数字按类型、进制、后缀三类属性识别，`017` 是八进制、`0x1F` 是十六进制、`123L` 带 `L` 后缀、`1e-3` 是浮点。

指导书表格里没有的字符，例如 `#`、`[`、`]`、`,`、`.`，一律按 E101 报非法字符。这是照着课程要求做的，不是漏写。

## 退出码

| 退出码 | 含义 |
| --- | --- |
| 0 | 扫描完成，没有词法错误 |
| 1 | 扫描完成，但存在词法错误，输出仍然完整 |
| 2 | 参数错误，或者文件读不了 |

## 测试

七组用例把七类记号、两种注释、各种数字写法、字符与字符串、九类错误、纯注释文件与空文件都过了一遍，比对方式是把实际输出与期望输出逐字节比。七组全过，结果在 `docs\测试结果.md`。

自己跑一遍：

```bat
code\tests\run_tests.bat
```

想留个存档，输出可以直接重定向：

```bat
code\bin\lexer-windows-x86_64.exe 你的代码.c > 结果.txt
```
