# c-lexer

《编译技术》实验一：C 语言子集的词法分析器。

程序读入一个源文件，逐个识别其中的记号，按行输出源程序与对应的二元式；注释与空白在识别过程中删除，不合法的写法给出带行列位置的诊断。

## 目录结构

| 位置 | 内容 |
| --- | --- |
| `lexer/include`、`lexer/src` | 源代码 |
| `lexer/bin` | 可执行文件（Linux x86_64，静态链接） |
| `lexer/examples` | 两个示例源程序 |
| `lexer/tests` | 测试用例、期望输出、比对脚本 |
| `docs` | 使用说明、测试结果 |
| `report/out` | 实验报告 |
| `report/latex` | 报告源文件 |

## 运行

```bash
./lexer/bin/lexer-linux-x86_64 源程序.c
```

示例：

```bash
./lexer/bin/lexer-linux-x86_64 lexer/examples/simple.c
```

命令行参数只有一个 `-h`，打印用法。程序的退出码见下文。

## 输出格式

```
=== lexer/examples/simple.c ===
  1 | { 最小示例：整数与浮点各声明一次 }
  2 | int main()
    | (6,"int") (6,"main") (7,"(") (7,")")
  3 |     int a = 3;
    | (6,"int") (1,"a") (7,"=") (2,"3") (7,";")
```

源程序逐行回显，行号占三列右对齐。该行有记号时，再输出一行以 `    | ` 起头，依次列出二元式 `(种别码,"属性")`，同一行的记号之间用空格分隔。空行与纯注释行只回显源程序。

种别码含义：

| 种别码 | 类别 |
| --- | --- |
| 1 | 标识符 |
| 2 | 整型常量 |
| 3 | 浮点常量 |
| 4 | 字符常量 |
| 5 | 字符串常量 |
| 6 | 保留字 |
| 7 | 运算符与界符 |
| 8 | 文件结束（不输出） |
| 9 | 词法错误 |

字符常量的属性值不带外层引号，`'x'` 输出为 `(4,"x")`，`'"'` 输出为 `(4,"\"")`。

末尾是统计区，给出行数、记号总数、错误数，以及按类别与整型常量进制的计数。

## 诊断

```
tests/cases/t05_error.c:2:10: E102 字符常量未闭合
  2 | char b = 'x;
    |          ^
```

诊断逐条列出，格式为「文件:行:列: 编码 说明」，随后回显该行原文并用 `^` 指向出错的字符。

| 编码 | 含义 |
| --- | --- |
| E101 | 非法字符 |
| E102 | 字符常量未闭合 |
| E103 | 字符常量内容为空或超过一个字符 |
| E104 | 非法转义序列 |
| E105 | 字符串常量未闭合 |
| E201 | 十六进制常量缺少数字 |
| E202 | 八进制常量中出现 8 或 9 |
| E203 | 浮点常量缺少指数部分 |
| E204 | 非法的数值后缀 |
| E301 | 注释未闭合 |
| E401 | 标识符长度超过 63 |

## 记号范围

保留字 21 个，取自指导书的表格（其中 `unsigned` 重复列出，按去重处理）：

```
auto  break  case  char  const  continue  do  double  else  enum
float if     int   long  main   return    static switch unsigned void while
```

运算符与界符：单字符 `+ - * / = < > ; ( )`，双字符 `== != <= >= && ||`。

注释支持 `{ }`、`//`、`/* */` 三种，均不允许嵌套。

数字按类型、进制、后缀三类属性识别，例如 `017` 为八进制整型、`0x1F` 为十六进制整型、`123L` 为带 `L` 后缀的整型、`1e-3` 为浮点。

未列于课程表的字符，例如 `#`、`[`、`]`、`,`、`.`，按 E101 报错。

## 退出码

| 退出码 | 含义 |
| --- | --- |
| 0 | 扫描完成且无词法错误 |
| 1 | 扫描完成但存在词法错误，输出仍然完整 |
| 2 | 参数错误或文件不可读 |

## 测试

七个用例覆盖正常程序、注释、数字、字符与字符串、错误与边界情形，逐字节比对期望输出，全部通过，结果见 `docs/测试结果.md`。比对脚本为 `lexer/tests/run_tests.sh`。
