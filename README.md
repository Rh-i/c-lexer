# c-lexer

编译技术课程实验一的作业：为 C 语言的一个子集实现词法分析器。

## 一、用途

程序读入一个源文件，从左到右识别其中的记号，按行回显源程序并输出该行的二元式。识别过程中删除行注释、块注释与空白字符，记录每个记号所在的行号与列号；遇到不合法的写法，给出带行列位置的诊断，并继续扫描后续内容。

## 二、目录结构

| 位置 | 内容 |
| --- | --- |
| `code\inc`、`code\src` | 源代码，四个模块与一个主程序 |
| `code\bin` | 编译好的可执行文件 `lexer-windows-x86_64.exe` |
| `code\examples` | 两个示例源程序 |
| `code\tests` | 七组用例、期望输出与比对脚本 |
| `docs` | 使用说明、测试结果、开发与构建说明 |
| `《编译技术》实验一报告-词法分析器.pdf` | 实验报告 |

## 三、运行

在命令行下有两种用法，效果相同。

第一种通过脚本调用：

```bat
code\run.bat 源程序.c
```

`run.bat` 先查找 `code\bin` 中的可执行文件，存在则直接运行；不存在时调用 CMake 完成构建，再运行刚生成的文件。构建只在首次运行时发生，之后的调用不会重复编译。

第二种直接调用可执行文件：

```bat
code\bin\lexer-windows-x86_64.exe 源程序.c
```

路径中包含中文或空格时无需额外处理。

自带的示例可以直接用来观察输出：

```bat
code\run.bat code\examples\simple.c
```

命令行只有一个参数 `-h`，用于打印用法说明。

## 四、输出格式

```
=== code\examples\simple.c ===
  1 | // 最小示例：整数与浮点各声明一次
  2 | int main()
    | (6,"int") (6,"main") (7,"(") (7,")")
  3 | {
    | (7,"{")
  4 |     int a = 3;
    | (6,"int") (1,"a") (7,"=") (2,"3") (7,";")
```

源程序逐行回显，行号右对齐，宽度随总行数变化，最少三列。该行存在记号时，再输出一行，以四个空格与竖线起头，依次列出二元式 `(种别码,"属性")`，记号之间用空格分隔。空行与整行注释只回显源程序，不输出记号。

种别码的含义如下：

| 种别码 | 类别 |
| --- | --- |
| 1 | 标识符 |
| 2 | 整型常量 |
| 3 | 浮点常量 |
| 4 | 字符常量 |
| 5 | 字符串常量 |
| 6 | 保留字 |
| 7 | 运算符与界符 |
| 8 | 文件结束（不输出） |
| 9 | 词法错误 |

字符常量的属性值不含外层引号，`'x'` 输出为 `(4,"x")`，`'"'` 输出为 `(4,"\"")`。

输出的末尾是统计区，给出行数、记号总数与错误数，并按类别、按整型常量的进制分别计数。

## 五、诊断

```
tests\cases\t05_error.c:2:10: E102 字符常量未闭合
  2 | char b = 'x;
    |          ^
```

每条诊断占三行：第一行为「文件:行:列: 编码 说明」，第二行回显该行原文，第三行用 `^` 指向出错的字符。

| 编码 | 含义 |
| --- | --- |
| E101 | 非法字符 |
| E102 | 字符常量未闭合 |
| E103 | 字符常量内容为空或超过一个字符 |
| E104 | 非法转义序列 |
| E105 | 字符串常量未闭合 |
| E201 | 十六进制常量缺少数字 |
| E202 | 八进制常量中出现 8 或 9 |
| E203 | 浮点常量缺少指数部分 |
| E204 | 非法的数值后缀 |
| E301 | 块注释未闭合 |
| E401 | 标识符长度超过 63 |

## 六、记号范围

保留字共 21 个，取自指导书的表格。表中 `unsigned` 重复列出一次，按去重处理：

```
auto  break  case  char  const  continue  do  double  else  enum
float if     int   long  main   return    static switch unsigned void while
```

运算符与界符共 16 个。单字符为 `+ - * / = < > ; ( ) { }`，双字符为 `== != <= >= && ||`。

注释有两种，`//` 到行尾结束，`/* */` 可以跨行，块注释不允许嵌套。花括号是语句块的界符，作用与 C 语言一致，函数体、`if` 与 `while` 的块都照常产生记号。

数字按类型、进制、后缀三类属性识别。`017` 为八进制整型，`0x1F` 为十六进制整型，`123L` 带 `L` 后缀，`1e-3` 为浮点。

指导书表格中未列出的字符，例如 `#`、`[`、`]`、`,`、`.`，按 E101 报非法字符。这是依据课程要求确定的处理方式。

## 七、退出码

| 退出码 | 含义 |
| --- | --- |
| 0 | 扫描完成且无词法错误 |
| 1 | 扫描完成但存在词法错误，输出仍然完整 |
| 2 | 参数错误或文件不可读 |

## 八、测试

七组用例覆盖七类记号、两种注释、各类数字写法、字符与字符串常量、九类错误、纯注释文件与空文件。比对方式是将实际输出与期望输出逐字节比较，七组全部通过，结果见 `docs\测试结果.md`。

重新执行比对：

```bat
code\tests\run_tests.bat
```

如果希望保存某次分析的输出，可以重定向到文件：

```bat
code\bin\lexer-windows-x86_64.exe 源程序.c > 结果.txt
```
