# 使用说明

## 一、运行

```bash
./lexer/bin/lexer-linux-x86_64 源程序.c
```

命令行参数只有 `-h`，用于打印用法。

## 二、输入要求

源文件按字节读入，UTF-8 与 ASCII 均可。语言子集如下。

空白只包括空格、回车符、制表符，程序是自由格式的，空白与注释在送语法分析之前删除。

注释有三种写法，都不允许嵌套：

```
{ 花括号注释 }
// 行注释，到行尾结束
/* 块注释，可跨行 */
```

标识符首字符为字母或下划线，其后是一个或多个字母、数字、下划线，长度不超过 63。

数字按三种属性区分：类型（整型或浮点）、进制（十进制、八进制、十六进制）、后缀。示例：

| 写法 | 类型 | 进制 | 后缀 |
| --- | --- | --- | --- |
| `123` | 整型 | 十进制 | 无 |
| `017` | 整型 | 八进制 | 无 |
| `0x1F` | 整型 | 十六进制 | 无 |
| `123L` | 整型 | 十进制 | `L` |
| `456ul` | 整型 | 十进制 | `ul` |
| `1.5` | 浮点 | 十进制 | 无 |
| `.5` | 浮点 | 十进制 | 无 |
| `1e-3` | 浮点 | 十进制 | 无 |
| `3.0F` | 浮点 | 十进制 | `F` |

字符常量由单引号包围，内容为一个字符或一个转义序列，可用转义为 `\n \t \r \0 \\ \' \"`。字符串常量由双引号包围，转义规则相同，不能跨行。

保留字表位于 `lexer/src/keyword_table.cpp`，标识符识别完成后查表决定是保留字还是一般标识符。

## 三、输出解读

```
=== 源文件路径 ===
  1 | { 例程 }
  2 | int main()
    | (6,"int") (6,"main") (7,"(") (7,")")
```

行号右对齐宽度 3，后面是 ` | ` 与源程序行。该行有记号时，再输出一行 `    | ` 加全部二元式，`(种别码,"属性")` 之间用空格分隔。

种别码含义：

| 种别码 | 类别 |
| --- | --- |
| 1 | 标识符 |
| 2 | 整型常量 |
| 3 | 浮点常量 |
| 4 | 字符常量 |
| 5 | 字符串常量 |
| 6 | 保留字 |
| 7 | 运算符与界符 |
| 8 | 文件结束（不输出） |
| 9 | 词法错误 |

字符常量的属性值不带外层引号，例如 `'x'` 输出为 `(4,"x")`，`'"'` 输出为 `(4,"\"")`。

有错误时追加诊断区：

```
--- 诊断 (1) ---
tests/cases/t05_error.c:1:9: E101 非法字符：#
  1 | int a = #;
    |         ^
```

冒号后的数字是行号与列号，插入符指向出错的字符。诊断之后是统计区，给出总行数、记号总数、错误数，以及按类别、按进制的计数。

## 四、退出码

| 退出码 | 含义 |
| --- | --- |
| 0 | 扫描完成且无词法错误 |
| 1 | 扫描完成但存在词法错误，输出仍然完整 |
| 2 | 参数错误或文件不可读 |

## 五、其他说明

同一份源程序在不同系统上的输出逐字节相同：读入按二进制处理，CRLF、单独的 CR 与 LF 都计为一个换行；Windows 端启动时关闭标准输出的换行转换，并把控制台代码页设为 UTF-8，因此中文路径与中文诊断都能正常显示。

测试用例的比对由 `lexer/tests/run_tests.sh` 完成，逐字节比较期望输出与实际输出，结果写入 `docs/测试结果.md`。
